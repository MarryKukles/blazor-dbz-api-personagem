# 🐉 Blazor Dragon Ball API

Uma aplicação web desenvolvida com **Blazor WebAssembly e C#**, que utiliza uma API de Dragon Ball para consultar e apresentar informações sobre personagens do universo da franquia.

O projeto tem como objetivo praticar o desenvolvimento de aplicações web com .NET, integração com APIs REST e construção de interfaces interativas utilizando componentes Razor.

## 🚀 Tecnologias utilizadas

- **C#** — Linguagem de programação.
- **.NET** — Plataforma de desenvolvimento.
- **Blazor WebAssembly** — Framework para construção da interface web.
- **HTML5 e CSS3** — Estrutura e estilização da aplicação.
- **Dragon Ball API** — API utilizada para obter informações sobre os personagens.

## 📌 Funcionalidades

- Consulta de informações de personagens do universo Dragon Ball.
- Integração com API REST para obtenção de dados.
- Exibição de informações consumidas externamente.
- Interface web desenvolvida com componentes Blazor.

## ⚙️ Como executar o projeto

### Pré-requisitos

Antes de começar, você precisará ter instalado:

- [.NET SDK](https://dotnet.microsoft.com/download)
- [Git](https://git-scm.com/)

### 1. Clone o repositório

```bash
git clone https://github.com/MarryKukles/blazor-dbz-api-personagem.git
```

### 2. Acesse a pasta do projeto

```bash
cd blazor-dbz-api-personagem
```

### 3. Restaure as dependências

```bash
dotnet restore
```

### 4. Execute a aplicação

```bash
dotnet run
```

Após iniciar, acesse o endereço local informado no terminal para visualizar a aplicação.

## 🌐 API utilizada

O projeto utiliza uma API externa relacionada ao universo Dragon Ball para obter informações dos personagens.

- Praticar desenvolvimento web utilizando C# e Blazor.
